스타일 가이드

개인 홈 컨트롤 앱. 선명·경쾌한 톤, 오프화이트 베이스 위에 잉크 뉴트럴 + 짙은 네이비 포인트 1색.

색은 “상태”를 말한다 — 켜진 기기만 네이비 틴트, 나머지는 뉴트럴. 수치는 크게, 라벨은 작게.

채택한 디자인 무브 (균형: 2개)

⑯ 크림/오프화이트 베이스

순백 #FFF 대신 페이지 배경을 쿨 오프화이트 #F4F5F2로. 카드는 순백이라 타일이 자연스럽게 떠 보이고 그림자 의존이 준다.

⑪ 극단적 위계 대비

11px 대문자 eyebrow 라벨 + 44px 수치(소비전력·사용량)를 병치. 중간 크기 남발 없이 크기 단계는 4개로 압축한다.

상태 색 규칙 — 타일에 적용하면

켜짐 = accent-soft 배경 + secondary 아이콘. 꺼짐 = surface. 오프라인 = 점선 테두리 + muted. 네이비는 대비가 높아(13:1) 상태 문구·링크 텍스트에도 쓸 수 있지만, 버튼 배경으로는 쓰지 않는다(primary = 잉크).
